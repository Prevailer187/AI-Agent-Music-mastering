# Audio catalog manifest

This public repository includes the source audio catalog supplied for the mastering work and the mastered deliverables available in the current workspace.

## Source audio

The `audio/source/` directory contains the supplied WAV and FLAC files, including LoudHouse2.0, GhanaHoliday, Vera variants, Bakery, ReviveMe, ReviveYou, TheSweetTrap variants, It'sUnusual, TikTokBaddie4.0, Sharon, DopeForeignNight, Whisper, Waka Na Dance, and Elevation.

## Mastered deliverables

The `audio/masters/` directory currently contains verified deliverables for:

- DopeForeignNight
- TheSweetTrapPart2
- Whisper

The `audio/radio-edits/` directory contains the Sharon clean/radio edit in normalized streaming/CD forms and louder peak-targeted alternates.

## Verification

- `SHA256SUMS.txt` records hashes for every included audio asset.
- Delivery measurements are printed by `scripts/master_audio.py` and should be re-run after any audio file is replaced.
- Audio files are included in the public repository at the repository owner's explicit request.
